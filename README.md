# 🌌 ATCleaner

> **Мощная и безопасная утилита для глубокой очистки операционной системы Windows, кэша популярных программ и оптимизации ОЗУ в один клик.**
> 🚀 *Помогает освободить до 15-20 ГБ скрытого цифрового мусора!*

---

## 🛠️ Главные возможности
* **Глубокая очистка Windows:** Полное удаление временных файлов (`Temp`), системных логов (`.log`) и раздутого кэша обновлений Windows (`SoftwareDistribution`).
* **Уничтожение игрового мусора:** Безопасная очистка кэша лаунчеров **Steam**, **Epic Games Store** и **EA App**.
* **Очистка мессенджеров:** Удаление медиа-кэша **Telegram** и **Discord** без потери важных данных аккаунта.
* **Браузерный клинер:** Очистка кэша и файлов `Code Cache` для Google Chrome, Яндекс.Браузера, Opera, Opera GX и Microsoft Edge.
* **Графический буст:** Удаление старых шейдеров видеокарт **NVIDIA** и **AMD** для устранения микро-фризов в играх.
* **Оптимизация ОЗУ:** Сброс системного кэша оперативной памяти (Standby List) для освобождения ресурсов перед тяжелыми играми.
* **Инструменты спасения:** Функция мгновенного перезапуска Проводника (`explorer.exe`) в случае зависания рабочего стола.

---

## ⚠️ Важные правила запуска
1. **Права Администратора:** Для полноценной работы очистки ОЗУ и системных логов Windows программу необходимо запускать строго через **правой кнопкой мыши -> Запуск от имени администратора**.
2. **Закрытие программ:** Для максимальной очистки рекомендуется закрыть Telegram, Discord, Steam и браузеры перед началом работы, иначе Windows заблокирует удаление их кэш-файлов.
