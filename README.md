# 🇬🇧 English
# 🌌 ATCleaner

> **A powerful, safe, and lightweight multilingual utility designed for deep Windows optimization, app cache removal, and RAM clearing in just one click.**
> 🚀 *Helps you free up to 15-20 GB of hidden digital junk! Supports both 🇷🇺 Russian and 🇬🇧 English languages.*

---

## 🛠️ Key Features
* **Deep Windows Cleaning:** Complete removal of temporary files (`Temp`), system logs (`.log`), and bloated Windows Update cache (`SoftwareDistribution`).
* **Game Launcher Cleanup:** Safe deletion of cache files from **Steam**, **Epic Games Store**, and **EA App**.
* **Messenger Cache Sweeper:** Safe removal of media caches from **Telegram** and **Discord** (fully optimized to prevent any app startup crashes).
* **Browser Cleaner:** Deletes cache and `Code Cache` files for Google Chrome, Yandex Browser, Opera, Opera GX, and Microsoft Edge.
* **Graphics Boost:** Clears outdated **NVIDIA** and **AMD** shader caches to eliminate micro-stutters and improve FPS in games.
* **RAM Optimization:** Flushes the Windows Standby List to free up system memory resources before launching heavy games (requires Admin rights).
* **System Rescue Tools:** Instant restart of the Windows Explorer process (`explorer.exe`) in case your desktop or taskbar freezes.
* **On-the-Fly Language Switch:** Easily toggle between English and Russian right inside the app interface.

---

## ⚠️ Important Usage Rules
1. **Administrator Rights:** To fully clean system logs and optimize RAM, you must launch the app by **right-clicking -> Run as administrator**.
2. **Close Background Apps:** For maximum efficiency, please close Telegram, Discord, Steam, and your web browsers before cleaning. Otherwise, Windows will lock and protect their cache files from deletion.
